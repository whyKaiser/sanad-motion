# سَنَد ٢ — مواد الشرح المتحرك

أدوات تُنتج شرحًا متحركًا لمنصة [سَنَد ٢](https://github.com/whyKaiser/sanad-v2): نسختان تعملان في المتصفح، ومقطع `MP4` يُبنى من لقطات الواجهة الفعلية.

كل النصوص عربية، وكل الأرقام مأخوذة من مستودع سَنَد ٢ نفسه — من `ml/evaluation.json` ووثائق `docs/`. الأشخاص والوثائق في اللقطات اصطناعية.

## ما في هذا المستودع

| المسار | المحتوى |
|---|---|
| `web/sanad-motion.html` | شرح موشن مرسوم بالكامل — ٢٨ مشهدًا، ٦:٢٢ دقيقة. رسوم متحركة لسلسلة التوقيعات، مصفوفة الصلاحيات، مقارنة متوسط الخطأ، ومحاكاة السعة. صفحة واحدة بلا اعتماديات. |
| `web/sanad-tour.html` | جولة بلقطات الواجهة الفعلية — ٣٤ مشهدًا، ٦:٢٧ دقيقة. يحتاج صور `ui/pNN.webp` بجانبه. |
| `tools/extract_shots.py` | ينزّل دليل الواجهات من مستودع سَنَد ٢ ويستخرج ٤٦ لقطة بصيغتي `PNG` و `WebP`. |
| `tools/build_video.py` | يبني مقطع `MP4` بدقة `1920×1080`: تقريب متحرك فوق اللقطات، تدرّج معتم، ونص عربي محروق في الصورة. |

مخرجات البناء كلها تحت `build/` وهي خارج التتبع — لا ملفات ثنائية في تاريخ المستودع.

## البناء

يتطلب `Python 3.10+` و `ffmpeg` مبنيًا مع `libass` و `harfbuzz` و `fribidi` (تشكيل العربية يعتمد عليها).

```bash
pip install -r requirements.txt
python tools/extract_shots.py
python tools/build_video.py
```

الناتج:

- `build/sanad-v2-motion.mp4` — الجودة الكاملة، نحو ٤٤ ميغابايت
- `build/sanad-v2-motion-light.mp4` — نسخة خفيفة، نحو ٢١ ميغابايت

يمكن تشغيل المراحل منفردة: `assets` للتدرّج والبطاقات وملف الترجمة، ثم `scenes` لمقاطع المشاهد، ثم `final` للدمج وحرق النص.

```bash
python tools/build_video.py scenes
```

## تشغيل النسختين في المتصفح

`web/sanad-motion.html` يفتح مباشرة بلا أي خطوة إضافية.

`web/sanad-tour.html` يحتاج الصور بجانبه:

```bash
python tools/extract_shots.py
mkdir -p web/ui && cp build/web/*.webp web/ui/
```

الاثنتان فيهما تشغيل وإيقاف، شريط زمن، تنقّل بين المشاهد، تحكم بالسرعة، اختصارات لوحة مفاتيح، وضع ليلي، وتخطيط يعمل على الجوال.

## ملاحظات تقنية

**تشكيل العربية في الفيديو:** النص يُحرق عبر `libass` من ملف `ASS` يولّده `build_video.py`. تباعد الحروف (`Spacing`) يكسر وصل الحروف ويعكس ترتيبها، لذلك يبقى صفرًا في كل الأنماط. وكل سطر مغلّف بـ `U+202B` و `U+202C` حتى لا تقفز علامات الترقيم إلى أول السطر.

**سرعة `zoompan`:** الفلتر يُخرج `d` إطارًا لكل إطار **مدخل**. تغذيته بصورة مكرّرة عبر `-loop 1` تضاعف العمل آلاف المرات؛ الصحيح إدخال إطار واحد وتحديد `-frames:v`. الفرق قياسًا: ١٫٣ ثانية للمشهد بدل ساعة.

## الحدود

المنصة نموذج أولي: لا ربط حكومي أو قنصلي فعلي، ولا قرارات آلية، ولا نسبة توفير ميدانية مثبتة. رقم `7.50%` تحسّن في **متوسط الخطأ** مقابل مرجع بسيط على ٦٬٧٧٣ ساعة اختبار — وليس «نسبة دقة». التفاصيل في وثائق سَنَد ٢.
